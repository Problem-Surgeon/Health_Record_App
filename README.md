# Health Records

A private family medical-records web app. Everything is stored **only on the device** (no server, no cloud).

## Put it online (GitHub Pages)
1. Create a new **public** repository on GitHub, e.g. `health`.
2. **Add file → Upload files** and drag in everything from this folder (keep the `icons` folder).
3. **Settings → Pages → Branch: `main` / root → Save.**
4. After about a minute the app is live at `https://YOUR-USERNAME.github.io/health/`.

## Install on iPhone
Open the link in **Safari**, then **Share → Add to Home Screen**. Always open it from that icon.

## Updating
Upload the changed files to the same repository. The app picks up the new version the next time it opens online. Your records stay.

## Keep your data safe
- Use **Backup → Save backup** now and then and keep the file in Files or Google Drive.
- Removing the home-screen icon deletes the app's data on iPhone.
